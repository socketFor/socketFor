# 导数和微分

导数：通过求割线斜率+极限思想 = 切线斜率

割线相当于求平均速度，当🔺t 趋近于 0 ，平均速度就转化为瞬时速度，也就是切线斜率。

导函数：就是原函数各点的切线斜率组成的函数。

导数**侧重**在说求**斜率**。

![导数图示](image-20251016114846-r20xfph.png)

微分：信号U(t)的微小增量，自变量t变化一点点，对应的函数也变化一点点。

![微分图示](image-20251016115005-1b687h1.png)

微分**侧重**在说求**增量**。
