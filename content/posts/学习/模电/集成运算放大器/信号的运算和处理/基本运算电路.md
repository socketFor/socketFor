# 基本运算电路

求解Uo和Ui之间的关系，有两个基本思路。

1.利用I<sub>R</sub>和I<sub>F</sub>相等去推导Uo和Ui之间的关系

2.利用叠加原理，分别去求Ui在U<sub>N</sub>上面的以及Uo在U<sub>N</sub>上面的影响然后再进行叠加，再去求Ui在U<sub>P</sub>上面的以及Ui在U<sub>P</sub>上面的影响然后再进行叠加，最后用虚短U<sub>P</sub> = U<sub>N</sub>，去推导出Uo和Ui之间的关系。

1.反相比例放大器

![image](/assets/image-20250915200956-x5x00jq.png)

![image](/assets/image-20250915201112-keusbau.png)

输入电阻非常非常小，符合并联负反馈的特征。Ri = 0，Ri’ = R，这个电阻R在反馈网络之外，与并联负反馈特征不矛盾。

要求：想要得到一个比较大的输入电阻又想得到一个比较大的放大倍数，我的RF又不想特别大，我该怎么做？因为电阻大容易被干扰。

![image](/assets/image-20250915202053-p99n69r.png)T 型网络反相比例运算电路的**输出与输入关系**为：$\boxed{u_O = -\frac{R_4}{R_1} \left(1 + \frac{R_2}{R_3}\right) u_I}$  

（负号表示输出与输入反相，比例系数由$R_1、R_2、R_3、R_4$共同决定）。

2.同相比例放大器

![image](/assets/image-20250916092908-90inv68.png)

电压串联负反馈，输入电阻无穷大，所以它可以很好的从信号源去抢信号。UP = UN = Ui，对于运放前级差放来说是共模信号。

电压串联负反馈：要求有比较好的共模抑制比。

电压并联负反馈：不需要有比较好的共模抑制比。

‍

为什么同相和反向比例电路输入端都有一个R'？

答：因为在静态的时候Ui = Uo = 0，UN和UP之间不是一点电流都没有的，U<sub>P</sub>和U<sub>N</sub>有电流流出，U<sub>P</sub> 始终等于0，但是U<sub>N</sub>等于R<sub>f</sub>和R的并联之后的分压，会导致U<sub>P</sub>≠U<sub>N</sub>，为了平衡流出和流入的电流保持一致不影响非静态时候的运算，这里加了一个R’去平衡静态时候U<sub>P</sub>=U<sub>N</sub>，此时的R'为平衡电阻，大小为R<sub>f</sub>//R。

7.差分运算电路

![image](/assets/image-20250916101622-6b02nbf.png)

u<sub>O</sub>=R/R<sub>f</sub>(u<sub>I2</sub>−u<sub>I1</sub>)

分析某一输入的特性时，需将其他输入置零，以排除其对电路的影响。

如果没有Rf，那么这个电路的输入电阻＝R（外电阻）+放大电路电阻（串联负反馈，输入电阻很大）=很大的输入电阻

这个差分比例电路，Ui1的输入电阻是R，Ui2的输入电阻是R+R<sub>f</sub>都不是很大。

问：怎么才能让这两个差分的输入电阻都很大呢?

答：​![image](/assets/image-20250916103844-d1arkeg.png)

若电路参数满足 $\frac{R_{f2}}{R_3} = 1 + \frac{R_{f1}}{R_1}$（通常为了使电路对称，会设计 $R_1 = R_3$、$R_{f1} = R_{f2}$，此时该等式成立），则上式可简化为：$u_O = \left(1 + \frac{R_{f2}}{R_3}\right) (u_{I2} - u_{I1})$

8.积分运算电路

![image](/assets/image-20250916120843-aga0z2l.png)

输出电压为$u_O(0)$，则：$u_O(t)=-\frac{1}{RC}\int_{0}^{t}u_1(\tau)d\tau + u_O(0)$

若初始条件为$u_O(0) = 0$（初始时刻电容无电荷），则简化为：$u_O(t)=-\frac{1}{RC}\int_{0}^{t}u_1(\tau)d\tau$  

‍

这里的Rf是用来给电容C进行放电的作用的，如果没有这么电阻进行放电，当C充满的时候，有一个放电的过程这个放电的过程会影响运放的运算速度，所以一般不会让这个电容充满。U<sub>C</sub> = Uo，有了这个电阻Rf以后，Uo不会达到-Rf/R*Ri。

![image](/assets/image-20250916161924-fxxcemg.png)

（b）电容C的充电电流和放电电流是恒定的，受Ui/R决定。充放电时间可求。

9.微分运算电路

![image](/assets/image-20250916162402-7gw1pff.png)

积分不会跃变，微分电路的输出能跃变。

![image](/assets/image-20250916162858-wcj8b8p.png)

稳压管：一对稳压管反向串联，可双向限幅。防止Ui输入类似阶跃信号，阶跃刚开始直接微分输出无穷大的I<sub>C</sub>电流，可能会烧毁R。

电容C1：相位补偿，这是一个滞后补偿，防止出现自激震荡。

### 推导输入输出关系

由$i_1 \approx i_f$，可得：$C\frac{du_I}{dt} \approx -\frac{u_O}{R}$整理可得输出电压$u_O$与输入电

压$u_I$的关系：$u_O \approx -RC\frac{du_I}{dt}$

 小节总结：![image](/assets/image-20250917110418-oc1wp3w.png)

比例，积分，微分，对数，指数运算，都是建立在比例运算的基础之上，用电阻R进行信号的转换。就比如，输入时Ui经过电阻变成i<sub>R</sub>，i<sub>R</sub>就是正向输入二极管的电流，二极管反馈出来的信号是电压又被Uo去接收。

加减运算，是基于KCL，在同相或者反向输入端完成一个电流的叠加，在用比例将电流信号转化为电压信号输出Uo
