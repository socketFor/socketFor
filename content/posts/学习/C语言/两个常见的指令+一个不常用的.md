# 两个常见的指令+一个不常用的

static 静态变量  ：在函数里面定义一个静态变量 例如 static a = 1；

作用：在此函数内，下次进入这个函数，变量不会被销毁，下次进入函数 a =1；

‍

extern 外部声明，我在一个模块里面定义了 一个数组或者变量 加上extern可以让这个变量在其他模块里面使用。
