# C语言指针

![微信截图_20250220143537](/assets/微信截图_20250220143537-20250220143553-w3xyw2z.png)

一个字节等于8个位 **。** 例如一个char型数据，0x66 这个数据就是八个位，你可能会有点疑问，为什么一个6代表了四个位，因为一个16进制数，最大是F，一个十六进制数要用4个二进制数去表示。

int a = 0x6666666

int* P = &a   如果你是一个64位操作系统，那么无论你是什么类型的指针都是64位的，也就是八个字节。

有了上面的铺垫，就可以理解为什么指针是间接访问了。

其实就是一句话：int型指针变量P存放了a的首地址，当我去用*P去取P地址下的内容的时候，编译器是先去看看指针P 里面存放的地址，但是不打印出来，而是去找该地址下对应的值是什么。

1.指针的运算

指针P的只有+ - ，而且加和减的都是指针数据类型的宽度，<u>通常用于数组上。</u>

*思考：如果我是一个int c[4]存放了四个int型变量 c的首地址指向的是第一个数组的数据，那么我c首地址加1存放的就是数组的第二个数据，如果我想访问第一个数据的第二个字节怎么访问呢*

补充：![微信截图_20250220150857](/assets/微信截图_20250220150857-20250220150909-f7l8hm4.png)

理解指针和数组之间的联系，数组名就是一个指针常量，里面存放了该数组的首地址。

注意：1.在对指针取内容之前一定要确保，该指针一定要是合法的，就好比你随便说一个门牌号，你都不知道这个门里面有什么，你就进去，甚至是不知道有没有这个门。

应用场景①：值传递参数

这种函数之间的传参方式其实是，经过了再定义一个相同的内存空间去复制被传参数。

指针传递

![微信截图_20250220153801](/assets/微信截图_20250220153801-20250220153811-26p94nq.png)

int型指针变量 array 接收了a数组的首地址 array[1]  =  *(a+1) ，中间无论数组的大小是多么大，只用开辟一个新的指针变量的大小即可。

应用场景②：多返回值函数的设计

![微信截图_20250220155843](/assets/微信截图_20250220155843-20250220155859-opdetky.png)

由于，指针传递用的数据，子函数和主函数是同一份数据，所以在子函数可以修改主函数里面的数据，子函数里面找到了最大值和返回值，直接修改主函数的参数，即可完成多返回值。

应用场景③：传递返回值

![微信图片_20250220161705](/assets/微信图片_20250220161705-20250220161730-82xgx28.png)

所以说，将模块内的共有部分返回，让主函数持有模块内共有部分的“句柄”便于程序对指定对象的操作。还有就是模块内的返回的公共部分一定要是你模块内的全局变量。

应用场景③：直接访问物理地址下的数据

![微信图片_20250220164604](/assets/微信图片_20250220164604-20250220164624-2uouc3l.png)

应用场景③：将复杂格式数据转化为字节

float a =12.345 由于float是占用了四个字节，这四个字节按照补码的形式存储的小数格式，但是在单片机里面发送数据一般是以字节的形式传输的，所以我们可以把float当作是一个四个字节的数组，用一个unsigned char型指针p去接收 float的首地址，然后把p通过通信传输到别的设备，在其他设备中定义一个float型指针去接收p 然后用取值去接受解码float数据，最后完成float数据以字节形式传输。

![微信截图_20250220170633](/assets/微信截图_20250220170633-20250220170732-6soyexm.png)

![微信截图_20250220170712](/assets/微信截图_20250220170712-20250220170732-dak918l.png)

总而言之，就是将一个复杂数据都看成是一个unsigned char 型的数组 最后把这个数组以数据包的形式传递出去，最后在要用的地方，以原来的数据类型进行解码就好了。
