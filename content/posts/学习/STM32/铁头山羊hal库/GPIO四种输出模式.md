# GPIO四种输出模式

1.通用开漏输出

2.通用推挽输出

3.复用开漏输出

4.复用推挽输出

# 通用和复用的区别

‍

通用是指：该GPIO口的输出状态是直接由主控芯片STM32F103C8T6直接控制的。

复用是指：该GPIO口的输出状态是由其他外设控制。

‍

# 推挽和开漏的区别

推挽是指：MOS管的P-MOS和N-MOS都用，意味着该IO口具备较强的驱动能力，可以设置默认输出为高或者为低。

开漏是指：MOS管中只使用N-MOS当N-MOS导通则该io口输出为低电平，若N-MOS管断开则该io口呈现为高阻态

![微信截图_20250319161451](/assets/微信截图_20250319161451-20250319161501-u4gv2al.png)

- **输出高阻态**：当内部逻辑控制信号使 MOS 管截止时，漏极与源极之间的通路断开，从 IO 口引脚看进去，相当于与地和电源都没有直接连接，此时 IO 口呈现高阻态。<u>这意味着 IO 口既不输出高电平也不输出低电平，它对外界电路的影响极小，就好像这个引脚在电气上与其他电路断开了一样。外部电路的电平状态不会被这个 IO 口所驱动或改变，而是由外部</u>​<u>上拉电阻</u><u>和</u>​<u>其他与之相连的电路</u><u>共同决定。</u>
- **接上拉电阻输出高电平**：只有在外部接上拉电阻到电源时，当 MOS 管截止处于高阻态时，由于上拉电阻的作用，IO 口引脚才能被拉到高电平。<u>如果没有上拉电阻，仅靠开漏输出本身在高阻态时是无法输出高电平的。</u>

‍

![微信截图_20250319165620](/assets/微信截图_20250319165620-20250319165919-y6d308k.png)![微信截图_20250319170046](/assets/微信截图_20250319170046-20250319170050-aizws9y.png)

1. **输入模式**

    - **浮空输入**：`GPIO_MODE_INPUT`​
    - **上拉输入**：`GPIO_MODE_INPUT`​，同时要把`GPIO_PULLUP`​配置给`GPIO_InitTypeDef.Pull`​。
    - **下拉输入**：`GPIO_MODE_INPUT`​，并且要将`GPIO_PULLDOWN`​配置到`GPIO_InitTypeDef.Pull`​。
2. **输出模式**

    - **推挽输出**：`GPIO_MODE_OUTPUT_PP`​
    - **开漏输出**：`GPIO_MODE_OUTPUT_OD`​
3. **复用功能模式**

    - **复用推挽**：`GPIO_MODE_AF_PP`​
    - **复用开漏**：`GPIO_MODE_AF_OD`​
4. **模拟模式**：`GPIO_MODE_ANALOG`​
5. **外部中断模式**

    - **上升沿触发**：`GPIO_MODE_IT_RISING`​
    - **下降沿触发**：`GPIO_MODE_IT_FALLING`​
    - **双边沿触发**：`GPIO_MODE_IT_RISING_FALLING`​
6. **外部事件模式**

    - **上升沿触发**：`GPIO_MODE_EVT_RISING`​
    - **下降沿触发**：`GPIO_MODE_EVT_FALLING`​
    - **双边沿触发**：`GPIO_MODE_EVT_RISING_FALLING`​
